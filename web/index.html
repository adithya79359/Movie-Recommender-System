How the selected model works

Movie ratings are smoothed toward the global mean, then discounted when very few ratings support a movie. The fitted statistics come from 6,726 training and validation ratings.

What personalization adds

Ridge combines movie content, a user preference profile and rating statistics. Custom profiles are an exploratory demo; reported scores come from existing MovieLens users.

Scope of the evidence

304 candidate title/year links cover 6.67% of the historical movie catalogue. Of these, 295 have reference ratings and are eligible for this deployment. Ratings are from MovieLens, not Hotstar.

Model deployment

The browser loads the fitted model artifact and computes rankings locally. No training runs during a recommendation.

The app supports a Python inference API when run locally using the supplied code.
